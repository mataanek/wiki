# Hermes Wiki Repository

This directory contains the Hermes wiki, including personal notes, concepts, band wiki, Netatmo data, smart home documentation, and ideation files.

## How to Use
- The wiki is used by Hermes for note-taking, ideation, and storage of persistent information.
- To add a new note, create a markdown file in an appropriate subdirectory (e.g., `concepts/`, `personal/`, `ideation/`).
- To update existing files, edit and commit changes.
- Push updates to the remote with `git push` (or set up a cron job to auto-pull/push).

## Branches
- `wiki`: current working branch for wiki.
