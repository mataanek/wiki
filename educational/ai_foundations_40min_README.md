# AI Foundations: 20 Concepts in 40 Minutes Presentation

## Course Overview
Single HTML presentation covering all 20 concepts from Rahul's thread in ~40 minutes (2 minutes per concept).

## File Location
`/home/mataanek/.hermes/wiki/educational/ai_foundations_40min.html`

## Features
- **Rapid-fire format**: 20 concepts, ~2 minutes each
- **Visual-first**: Each concept includes a visual analogy using curated images
- **Interactive knowledge check**: Press SPACE to reveal answer during presentation
- **Navigation**: LEFT/RIGHT arrows or on-screen buttons to move between concepts
- **Clean presentation design**: Optimized for projector/screen sharing
- **Timer suggestion**: Built-in progress indicator showing concept #/20

## Concept Flow (per slide):
1. Concept number & title (large, prominent)
2. One-sentence core explanation
3. Visual analogy (1 sentence) 
4. Knowledge check question
5. [Presenter speaks, audience thinks]
6. Presenter presses SPACE → reveals answer
7. Brief reward/confirmation message
8. Move to next concept

## Usage
1. Open the HTML file in any modern browser (Chrome, Firefox, Safari)
2. Use LEFT/RIGHT arrows or click buttons to navigate
3. During presentation, press SPACE to reveal answer after asking the question
4. Suggested pacing: ~2 minutes/concept = 40 minutes total

## Customization
- To adjust timing: change your speaking pace, not the slides
- To add more depth: expand on concepts during your verbal presentation
- To reuse: the presentation stands alone or can be supplemented with discussion
